# entrada/

Coloque aqui as gravações brutas (Motor A), uma pasta por VSL:

```
entrada/<slug-da-vsl>/01-hook.mp4
entrada/<slug-da-vsl>/02-historia.mp4
...
```

O nome de cada arquivo aparece no roteiro (`vsl.py takes <slug>` lista o que falta).
Para a gravação-guia do /comecar: `entrada/teste-guia/`.
Roteiros que você trouxer (Word, PDF, texto) também podem ficar aqui.

Os vídeos desta pasta ficam só no seu computador (não vão para o git).
